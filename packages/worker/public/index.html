r2-fastlink
GitHub

Share a file with an agent. Let the link expire on its own.

Upload to your own Cloudflare R2 bucket and get a short public link that stops working after an hour, or whatever you choose. Need it again later? Refresh it and the same link works for another window. 

$ r2fl up screenshot.png
✓ screenshot.png (1.2 MB) · expires 14:32
https://fl.example.com/k3F9xQ2m

$ curl -sI https://fl.example.com/k3F9xQ2m | head -1
HTTP/2 200

# an hour later…
$ curl -sI https://fl.example.com/k3F9xQ2m | head -1
HTTP/2 410

$ r2fl refresh k3F9xQ2m --ttl 30m
✓ k3F9xQ2m is live again until 15:41

Built for handing files to coding agents

Short and direct

Eight characters, served as the raw file with the right content type. No redirects, no login, nothing for an agent to trip over.

Expires by itself

One hour by default, set globally or per upload. Close a link early or cap its downloads when you need to.

Yours alone

One Worker, one Durable Object and a private bucket in your own Cloudflare account. History stays on your machine.

Already set up? Upload with the CLI

  1. Point the CLI at this Worker with your upload token:

    $ r2fl init --endpoint https://fl.example.com

  2. Upload, with an optional lifetime:

    $ r2fl up report.pdf
$ r2fl up build.log --ttl 15m
$ cat trace.txt | r2fl up --name trace.txt

  3. Manage links from your local history:

    $ r2fl ls
$ r2fl refresh k3F9xQ2m
$ r2fl revoke k3F9xQ2m

Curious? Run your own

This is a personal, single-user tool, so there is nothing to sign up for here. To try it, fork the repo and deploy it to your own Cloudflare account. It runs on the free plan. 

$ git clone https://github.com/crcatala/r2-fastlink
$ cd r2-fastlink && pnpm install
$ pnpm --filter @r2-fastlink/worker exec wrangler r2 bucket create r2-fastlink --no-update-config
$ pnpm --filter @r2-fastlink/worker exec wrangler secret put R2FL_TOKEN
$ pnpm --filter @r2-fastlink/worker deploy
